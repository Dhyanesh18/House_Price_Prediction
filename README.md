# BANGLORE HOUSING PRICE PREDICTION

A standard dataset from Kaggle was used in the project.
This was my first end to end ML project that is pretty basic which i did soon after learning the basics of ML in 2024 Jan at the beginning of my second semester.
Docker containerization and deployment on Render has been done recently.

~ Performed Grid Search for multiple different models and configurations. 

~ Linear Regression turned out to give the best Accuracy among the tested ones ~84.5%
